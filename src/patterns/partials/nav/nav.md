title: Navigation
---

The main navigation from `site.navigations.main`: each entry a page (`route`), a link (`href`, opened in a
new tab when it leads to another site) or a group (`children`, shown as a label with a sub-list). On narrow
screens the menu button opens it (`site` script).

Formerly `layouts/partials/nav/main.html` with the Hugo menu in `config/_default/menus.yaml`.
