The frame every layout fills: the header with the logo and the main navigation, and the main content
(`main#swup`, the container swup's page transitions swap). A layout fills it with
`{{#> partials-base }} … {{/partials-base}}`.

Formerly the Hugo theme's `layouts/_default/baseof.html`. Its footer partial was empty and is gone.
